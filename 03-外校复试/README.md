# 03 · 外校复试

拿到本校名额之后（见 [02-本校保研资格](../02-本校保研资格/)），第二关是拿到目标学校的 **offer**。这一目录讲这条链路具体长什么样、每一环考什么、怎么准备。

## 一句话总结这一关的本质

- **初筛看"你是谁"**：学校层次、排名、论文、竞赛——短期改不了的部分；
- **复试看"你能做什么"**：机试写代码、面试讲清楚自己的工作——这部分可以在几个月内明显提升。

所以策略通常是：初筛的牌尽量早打（大一到大三上），复试的功夫留到投递前后集中练。
