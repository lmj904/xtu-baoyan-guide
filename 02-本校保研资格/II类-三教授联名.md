# Ⅱ类：三教授联名推荐

> 适用年份：2023 级（2026 年推免）
> 最后更新：2026 年 10 月
> 来源：[学院官方通知](https://jwxy.xtu.edu.cn/info/1018/5019.htm)、[《湘潭大学教授联名推荐优秀应届本科毕业生免试攻读研究生工作实施细则》]

> ⚠️ **这一类的名额只能保研到本校。** 想保外校的同学请看 [Ⅰ类](I类-综合成绩排名.md)。

## 定位：给"绩点不够但成果硬"的人一条路

Ⅰ类卡死在绩点前 20%，Ⅱ类放宽到**前 50%**，用"特殊学术专长 / 突出培养潜质 / 实质性先进事迹"来替代排名的权重。

## 一、基本条件

1. 符合Ⅰ类基本条件**第 1、2、8 条**（学校推免生基本条件、英语要求、以及遴选与材料认定的相关规定）；
2. 必修课程平均学分绩点排名在所学专业**前 50%**，且有特殊学术专长或突出培养潜质、具有实质性先进事迹。

## 二、推荐机制

- 由**三名以上**本校本学科、专业教授**亲自撰写推荐材料并亲笔签名**推荐；
- 推荐信中必须说明被推荐学生的**综合表现**；
- 经**学院学术委员会**会议审查，**学校推免生遴选工作领导小组**审定；
- 可以**不受综合排名限制**；
- 学生的有关说明材料和教授联名推荐信须在**学院公示**；
- 教授联名推荐可占学院**总指标的 30% 左右**，具体按《湘潭大学教授联名推荐优秀应届本科毕业生免试攻读研究生工作实施细则》执行；
- **针对实验班学生**：推荐方式所对应的排名要求，可在"班级实际分配推免指标占实验班人数比例"的基础上，再往后**放宽 20%**。

## 三、对教授的约束（很重要）

| 约束 | 后果 |
| --- | --- |
| 每名教授每年限推荐学生**不得超过 3 名** | — |
| 推荐信须着重说明学术专长、培养潜质、实质性先进事迹与综合表现，并建议至具体课题组 | — |
| 推荐了但未被学校审定录取的指标被学校收回 | 该教授**三年内不具备推荐资格** |
| 教授与拟推荐学生有直系亲属关系或其他影响公正的因素，应当**回避** | 否则取消被推荐学生的推免资格 |
| 教授隐瞒应回避事项、帮助或纵容材料造假 | **永久**停止其推荐学生资格 |

这就意味着：找教授推荐不是"签个字"的事，老师要押上自己的推荐资格。所以联名推荐的前提是你的成果真的经得起审。

## 四、审核流程

- 学院成立**专家审核小组**：成员原则上具有相关学科**副教授以上**职称，一般**不少于 5 人**；
- 会同相关期刊杂志单位、赛事主办单位等，对科研创新成果、论文、竞赛获奖的**奖项及内容**进行审核鉴定，排除抄袭、造假、冒名、有名无实等情况；
- 组织申请学生进行**公开答辩**，专家审核小组及每位成员都要给出明确审核意见并签字存档；
- 答辩**全程录音录像**，结果**公开公示**；
- 未通过审核鉴定或答辩的学生**不得推荐**。

## 五、"实质性先进事迹"的四类认定

需符合《细则》要求，且具备下列之一：

**(1) 论文**

在下列范围内，以**独立作者或第一作者**发表的、与学业相关的科研论文：

- SCI、EI 源刊
- CCF A / B / C 类会议及期刊
- SSCI、A&HCI、CSSCI 及其扩展版
- CSCD
- 《中文核心期刊要目总览》（北大核心）

> 期刊认定标准以**论文发表时**该期刊所属目录版本为准。智库成果可参照《湘潭大学智库研究成果认定办法（试行）》视同相应级别论文。

**(2) 专利**

以**第一发明人**获得与学科专业相关的**国家发明专利授权**。

**(3) 竞赛**

作为**主力成员**参加各类与学业相关的学科竞赛（全国赛）并获得**三等奖及以上**奖励（国际赛事参照执行，但不得低于国内赛事相关要求）。

主力成员的界定：

| 赛事 | 主力范围 |
| --- | --- |
| 国际大学生程序设计大赛亚洲分区赛、中国国际大学生创新大赛、"挑战杯"全国大学生课外学术科技作品竞赛、湖南省"金种子"杯大学生创业大赛 | 排名**前 6** |
| A 类学科竞赛 | 排名**前 4** |
| B 类学科竞赛 | 排名**前 3** |
| C 类学科竞赛 | 排名**前 2** |

**(4) 其他**

其他具有公信力的突出业绩。要求是**非人为主观评价**的成果，必须提供相应的事实证明。

## 六、推荐程序（五步）

1. **学生申报**：向学院提交个人申请表、个人成绩单（加盖学院及教务处公章）、先进事迹证明材料、教授推荐材料；
2. **材料审查与公示**：学院审查申报材料（含教授推荐信），并在学院初步公示；
3. **综合测评**：材料公示无异议后，学院召开学术委员会，申报学生须**到场参加**；全体推荐教授须到场说明推荐意见；学术委员会审议是否同意推荐；
4. **学院审定**：学术委员会通过的学生，由学院推免生遴选工作领导小组审定，确定推荐名额及推荐学生；
5. **公示与上报**：正式公示无异议后，学院将推荐名单和材料报学校教务处审定。

## 现实提醒

- Ⅱ类**只能留本校**，如果你的目标是外校，这条路直接排除；
- 名额占比约 30%，但要求的是"实质性成果"——论文、专利、竞赛主力，都不是临时能凑出来的；
- 找教授签字前，先确认自己的成果落在上面四类里的哪一类，别到答辩环节被审核小组刷掉。
