# 绩点与加权成绩

> 适用年份：2023 级（2026 年推免）
> 最后更新：2026 年 10 月
> 来源：湘潭大学教务规定 + 个人整理

推免的各种门槛里，最先要算清楚的就是这两个数。它们都建立在同一套原始成绩上，只是算法不同。

## 一、绩点：4 分制分段换算

湘潭大学采用 **4 分制**，按分数区间分段确定绩点：

| 分数区间 | 等级 | 绩点 |
| --- | --- | --- |
| 90–100 | A | 4.0 |
| 85–89 | A- | 3.7 |
| 82–84 | B+ | 3.3 |
| 78–81 | B | 3.0 |
| 75–77 | B- | 2.7 |
| 72–74 | C+ | 2.3 |
| 68–71 | C | 2.0 |
| 64–67 | C- | 1.5 |
| 60–63 | D | 1.0 |
| 60 以下 | F（不及格） | 0 |

## 二、单科学分绩点

$$
\text{学分绩点} = \text{课程绩点} \times \text{课程学分}
$$

例如：某课程 3 学分，成绩 85 分（对应绩点 3.7），则学分绩点 $= 3.7 \times 3 = 11.1$。

## 三、平均学分绩点（GPA）

$$
\text{GPA} = \frac{\sum(\text{课程绩点} \times \text{课程学分})}{\sum \text{课程学分}}
$$

即"所有课程学分绩点之和 ÷ 所修课程总学分数"。

**举例**：修读三门课，学分分别为 2、3、4，对应学分绩点为 8.0、9.0、16.0，则

$$
\text{GPA} = \frac{8.0 + 9.0 + 16.0}{2 + 3 + 4} = \frac{33}{9} = 3.67
$$

## 四、加权成绩排名（不带绩点的算法）

**加权成绩排名不算绩点**，而是直接拿学分当权重、对分数做加权平均：

$$
\text{加权成绩} = \frac{\sum(\text{课程成绩} \times \text{课程学分})}{\sum \text{课程学分}}
$$

它的用途是：Ⅰ类测评里的"学业成绩"这一项，用的就是必修课的加权平均分（详见 [I类-测评计分办法](I类-测评计分办法.md)），而不是 GPA。

## 五、补考与重修

| 情况 | 规则 |
| --- | --- |
| 补考通过 | 该课程绩点**统一记 1.0**，不管补考考了多少分 |
| 重修 | 按**实际成绩**计算绩点，但**原始成绩仍然保留在成绩单上** |

这两条对排名影响很大：一门课挂了再补考，绩点最多 1.0；重修能刷高绩点，但成绩单上会留下痕迹（保研材料通常要交成绩单，复试老师可能看得到）。

## 六、哪些课算进"必修课平均学分绩点排名"

> **特别说明（官方口径）**：纳入必修课程平均学分绩点排名的课程，指的是**截至学校当年发布推荐免试攻读研究生通知之日，已提交所有学生成绩的必修课程**。

也就是说：

- 只算**必修**课，选修课不进这个排名（但选修课成绩在综合测评环节会作为材料提交）；
- 时间点卡在"通知发布之日"，那之后才出成绩的课不算；
- 挂科、重修、缓考的课怎么计入，以当年教务处口径为准。
