# xtu-baoyan · 湘潭大学计算机学院保研指南

一份面向湘潭大学计算机学院学生的保研（推免）指南，按主题拆成多个子目录，方便按需查、也方便大家一起补充。

## 面向人群

- 湘潭大学计算机学院（及相关专业）在读本科生：正在考虑保研、已经决定保研，或只是想知道保研是怎么回事
- 大一、大二想提前规划的同学，以及大三正在准备材料、投递和复试的同学
- 愿意把自己的经验写下来、帮到后来人的本校同学与学长学姐

其他学院、其他学校的同学也能读其中的通用部分（保研基础、复试流程、竞赛、科研），但**本校政策部分只对湘潭大学计算机学院有效**，请以自己学院的文件为准。

## 前言

本文是湘潭大学计算机学院保研政策的分享，讲的是如何取得本校推免资格、如何保研到更好的学校。不同学院的保研政策不一样，其他学院的同学请咨询本专业的学长学姐。

保研不是大学的目的，也不是每个人都该去卷的结果。它只是诸多选择中的一种——希望你先想清楚自己要不要走这条路，再决定要不要投入，而不是盲目跟着别人一起卷。

计算机大类有一个保研互助组织叫**绿群**，群里沉淀了大量通用的保研信息（基础知识、院校信息、经验帖）。本指南的重点放在对湘潭大学计算机学院学生更精确、更适用的部分，建议先读完本指南，再去看绿群的资料（入口见 [信息渠道与工具](01-保研基础知识/信息渠道与工具.md)）。

> **声明**：本指南整理自湘潭大学计算机学院历年推免政策与同学的个人经验，最近更新于 2026 年 10 月。政策每年都可能调整，最终以湘潭大学教务处、计算机学院当年发布的官方通知为准。本指南不构成官方承诺，也不代表学院立场。
