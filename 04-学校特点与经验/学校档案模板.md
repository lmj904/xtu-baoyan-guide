# 学校档案模板

新增一所学校的经验时，**复制这一页**，重命名为"学校中文全称.md"（例如 `北京理工大学.md`），然后按下面的结构填写。

**填写原则**：

- 只写你能确认的，不确定的写 `待补充`，不要猜；
- 每个判断都带年份（"据 2025 年参加者反馈"）；
- 主观感受要标明是主观；
- 不写个人隐私、不写导师的私下承诺。

---

## 模板正文（从这里开始复制）

# 学校名称

> 适用年份：20XX 级（20XX 年推免）
> 最后更新：20XX 年 XX 月
> 来源：个人经历 / 学长口述 / 官网通知 / 群内经验帖

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 院所/学院 | 例：计算机科学与技术学院 |
| 强弱 COM | 强 / 弱 / 因学院而异 / 待补充 |
| 初筛偏好 | 例：看重排名与论文，ACM 加分明显 |
| 复试形式 | 机试 + 面试 / 机试 + 笔试 + 面试 / 仅面试 |
| 是否卡本科 | 是否明确限制 985/211 |
| 关键时间 | 夏令营投递 5 月、预推免 9 月（按实际记录） |

## 初筛

写清楚：材料交什么、按什么筛、有没有老师能影响结果、往年大概什么样的 bg 能进。

## 复试

### 机试

- 形式：几道题、多长时间、什么平台
- 难度：大概什么水平（相当于洛谷/LeetCode 什么段位）
- 内容：算法为主？还是有工程题

### 笔试

- 科目：数据结构 / 操作系统 / 网络 / 组成原理 / 数学……
- 题型与难度

### 面试

- 形式：单面 / 群面 / 英文面；几位老师；多长时间
- 问什么：项目、论文、专业课、英语、兴趣
- 印象深刻的题目（可以列几道）

## 课题组 / 导师

- 哪些组对本科生友好、哪些组认可竞赛牌子
- 是否接受提前进组、线上还是线下
- 只写公开可查的信息和你自己的体验，不要写私下承诺

## 个人感受

- 值得去吗？为什么？
- 有什么坑（比如某环节特别重要、某类材料容易漏）
- 和其他同类学校比，差异在哪
