# 04 · 学校特点与经验

一校一页的经验卡片。每页记录这所学校的强弱 COM 属性、初筛偏好、复试形式、以及和课题组相关的零散信息。

> ⚠️ **所有内容都带年份**。学校的招生方式、老师的态度、门槛都会变，看到两年前的经验请先打个问号，投递前用当年通知核对。

## 现在只有四所学校，欢迎补齐

这个目录目前还很空——只收录了原指南里提到过的几所学校。**你的经验正是这里最缺的东西**：

- 参加过某校夏令营/预推免的，哪怕只写"考了什么、什么时候出结果"，也很有价值；
- 不用写得漂亮，流水账也行；
- 不会 Git 就直接开 Issue 贴文字（见 [CONTRIBUTING](../CONTRIBUTING.md)）。

新增一所学校的步骤：

1. 复制 [学校档案模板](学校档案模板.md)，重命名为"学校中文全称.md"；
2. 填你能确认的部分，不确定的留 `待补充`；
3. 在本目录的索引表和 [院校名单速查](院校名单速查.md) 里各补一行。
