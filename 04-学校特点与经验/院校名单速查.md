# 院校名单速查

> 适用年份：2023 级（2026 年推免）
> 最后更新：2026 年 10 月
> 来源：个人经验整理

> ⚠️ 以下名单基于 2023 级的经验，**学校每年可能调整招生方式**。用之前请用当年信息核对。

## 一、常见弱 COM 学校

弱 COM 意味着老师话语权大，**基本必须提前联系老师**（除非 bg 特别强——但大家都是湘大本科，通常不具备这个条件）。详见 [强 COM 与弱 COM](../01-保研基础知识/强COM与弱COM.md)。

| 学校 / 项目 | 说明 |
| --- | --- |
| 大部分（甚至所有）学校的**直博**项目 | 直博一般由导师主导 |
| **华东师范大学** 计算机学院 | 详见 [华师大卡片](华东师范大学.md) |
| **厦门大学** 信息学院、AI 学院 | 详见 [厦大卡片](厦门大学.md) |
| **中国科学技术大学** | — |
| **中山大学** | — |
| **华中科技大学** | — |

## 二、明确卡 985 本科的学校

这类学校初筛基本只看本科层次，双非投递大概率是白费功夫

| 学校 | 说明 |
| --- | --- |
| **武汉大学** | 明确卡 985 |
| **哈尔滨工业大学** | 明确卡 985 |

> 这条不是绝对真理。每年都有例外，但例外通常意味着你有非常强的论文或竞赛背书。

## 三、湘大的优势区间：只卡"双一流"的学校

这一类学校的门槛设在**双一流**，而湘潭大学正好是双一流——2022 年 2 月第二轮"双一流"名单公布，数学学科入选世界一流学科建设名单（[见学校官网](https://www.xtu.edu.cn/info/1039/1011.htm)）。

也就是说：**它们不会因为本科身份把湘大筛掉**，是湘大相对"够得着"的一档，值得当作主攻方向来投。

| 学校 | 门槛 |
| --- | --- |
| **西安电子科技大学** | 卡双一流 |
| **南京理工大学** | 卡双一流 |
| **南京航空航天大学** | 卡双一流 |
| **深圳大学** | 卡双一流 |

三档门槛放一起对比，思路就清楚了：

| 门槛类型 | 湘大是否满足 | 投递建议 |
| --- | --- | --- |
| 卡 985 / 211（上一节） | ❌ 不满足 | 基本不用投，除非有非常硬的成果 |
| **卡双一流（本节）** | ✅ **满足** | **主攻区间，重点投** |
| 不设本科门槛 | ✅ 满足 | 看其他条件，自由竞争 |

### 两个要留意的地方

1. **名单和口径每年都在变**，投递前用当年通知核对；
2. **过门槛 ≠ 有优势**：不被卡身份只解决了初筛的第一道关，最终还是要看排名、论文、竞赛和复试表现。

## 四、强弱 COM 会变

**同一所学校不同年份可能改变招生方式**，两个方向的例子：

| 学校 | 变化 |
| --- | --- |
| 东南大学（计算机 / 软件 / 人工智能） | 2026 年由**弱 COM 变为强 COM** |

所以：

- 不要拿两年前的经验直接套；
- 投递前确认当年情况（问学长、看群消息、看学院通知）。

## 五、强 COM 学校

强 COM 不是"不用联系老师"，而是"老师不能替你翻盘"——联系仍然有用，只是权重低，硬指标和机试才是决定性的。

已知的强 COM 记录（欢迎补充）：

| 学校 / 学院 | 说明 | 依据 |
| --- | --- | --- |
| **北京航空航天大学** | 几乎所有计算机相关学院都是强 COM | [学校卡片](北京航空航天大学.md) |
| **华东师范大学** 软件学院 | 软件学院强 COM（其计算机学院是弱 COM） | [学校卡片](华东师范大学.md) |
| **东南大学**（计算机 / 软件 / 人工智能） | 2026 年由弱 COM 变为强 COM | 见本文第四节 |

> 想补一所新学校：按 [学校档案模板](学校档案模板.md) 写一页卡片，再在上表加一行，注明判断依据和年份。

## 怎么用这份名单

1. 先按门槛分三档：卡 985/211 的基本放弃（除非成果极硬）；**只卡双一流的正是湘大能投的区间，重点放在这里**（见第三节）；不设本科门槛的自由竞争；
2. 弱 COM 的学校：把"联系老师"排进时间表，越早越好；
3. 强 COM 的学校：把精力放在硬指标和机试上；
4. 每年 3–6 月重新核对一遍——名单会过期。
