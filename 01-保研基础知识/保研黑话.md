# 保研黑话

> 最后更新：2026 年 10 月
> 来源：个人整理

群里、经验帖里到处是缩写，看不懂很正常。这一页按首字母和常用度整理，遇到不认识的回来查即可。欢迎补充新词条。

## 核心缩写

| 黑话 | 全称 / 原文 | 意思 |
| --- | --- | --- |
| **bg** | background | 背景。指你的学校层次、专业排名、竞赛、科研、英语等综合条件的总称，是初筛时被评估的对象 |
| **rk / rank** | rank | 排名。分排名百分比、绝对排名、相对排名等，不同学校的要求不一样 |
| **bar** | barrier | 入营门槛。指某所学校/某个组当年能进复试的最低条件 |
| **com** | committee | 招生委员会 / 招生办。衍生出 [强 COM 与弱 COM](强COM与弱COM.md) |
| **wl** | wait list | 候补名单。前面的人放弃后依次递补 |
| **oq** | over qualified | 你条件太好，学校怕你最后不来（鸽），索性不给入营 |
| **鸽** | — | 拿到 offer 后放弃不去。学校也怕被"鸽"，所以会防 oq |

## 动作类

| 黑话 | 意思 |
| --- | --- |
| **套磁** | 套近乎、搞好关系。指主动给老师发邮件、介绍自己、表达想进组的意愿。详见 [套磁](../06-科研/套磁.md) |
| **入营** | 通过初筛，获得参加夏令营/复试的资格 |

## 专业代码（"代码"）

投递时经常要选专业代码，代码决定了你读的是学硕还是专硕：

| 代码 | 专业 | 类型 |
| --- | --- | --- |
| 0812 | 计算机科学与技术 | 学硕 |
| 0835 | 软件工程 | 学硕 |
| 0839 | 网络空间安全 | 学硕 |
| 085400 | 电子信息类 | 专硕（大类） |
| 085404 | 计算机技术 | 专硕（对应 0812） |
| 085405 | 软件工程 | 专硕（对应 0835） |
| 085412 | 网络与信息安全 | 专硕（对应 0839） |

> 工程硕博改革专项通常都归在 085400 下。

## 培养层次

- **学硕 / 专硕 / 学博 / 专博 / 工程硕博**：基本的培养类型区分；
- **联培**：例如国智院、AILab、通研院等联合培养项目；
- 计算机方向还有各种**专项**，这类项目往往要抱着"吃螃蟹"的心态——但也可能竞争较小，是上岸梦校的机会。建议前期多了解，别到报名时才第一次听说。但是风险与机遇并存，许多专项也有各自的坑点，至于是否选择就见仁见智了。
