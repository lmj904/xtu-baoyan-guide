# 01 · 保研基础知识

保研的"世界观"部分：它到底是什么、整个流程长什么样、那些到处出现的缩写是什么意思。这几页不涉及湘大的具体政策，读完它们再去看 [02-本校保研资格](../02-本校保研资格/) 会顺很多。

## 建议阅读顺序

1. 先看 [保研是什么](保研是什么.md)，确认自己要不要走这条路；
2. 再看 [申请流程](申请流程.md)，建立整体印象；
3. 边看边翻 [保研黑话](保研黑话.md)，群里的缩写基本都能查到；
4. 开始投递前，重点看 [强 COM 与弱 COM](强COM与弱COM.md)；
5. 需要外部资料时，去 [信息渠道与工具](信息渠道与工具.md)。
