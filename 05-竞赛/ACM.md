# ACM

> 适用年份：2023 级（2026 年推免）
> 最后更新：2026 年 10 月
> 来源：个人经验（原文作者为 ACM 队成员，视角带有个人色彩，请自行判断）

## 一句话结论

**收益很高，难度也很高。** 适合两类人，不适合大多数人。

## 一、收益：为什么 ACM 值钱

### 1. 复试机试几乎碾压

对设有机试的学校，参加过 ACM 训练的人**基本能拿到极高分**。复试是打分排名制，机试分差往往决定你排在 offer 区还是候补区。

### 2. 很多学校和老师认可牌子

原文点名的例子（2023 级经验）：

| 学校 / 组 | 对 ACM 的态度 |
| --- | --- |
| 华东师范大学 | 有 ACM 牌子"点击就送"（口头说法，指认可度最高一档） |
| 北京航空航天大学 | 优待 ACM 牌子；没有牌子，双非几乎不可能进 |
| 西安电子科技大学 王楠楠组 | 老师对牌子认可度高 |
| 厦门大学 csn 实验室 沈思琪组 | 老师对牌子认可度高 |

2023 级 ACM 队内三位保研同学的去向分别是：**厦门大学、华东师范大学、北京航空航天大学**。

### 3. 银牌可以直接换名额

据原文：**ACM 银牌就可以获得奖励名额，只要必修绩点在前 20% 就能直接保研**。对应的政策口径见 [Ⅲ类-学校奖励指标](../02-本校保研资格/III类-学校奖励指标.md)（注意该类政策仍在变更期，以官方新文件为准）。

## 二、难度：为什么多数人不该选

- **参赛人数被严格控制**：不是想打就能打，队里名额有限；
- **对手里有很多 OI 生**：中学就有竞赛底子的人在这条赛道上天然领先；
- **训练极其耗时**：需要长期、高强度的投入，不是"抽空练练"能达到的水平。

但也不必被吓住：原文提到，**队内 0 基础的金牌、银牌也不少**。不是说非 OI 出身就没戏，而是说这条路需要真正的时间投入。

## 三、只建议这两类人参加

**(1) 中学有 OI 基础，并且有训练的意愿与精力。**

**(2) 在学习 C 语言程序设计 1、以及在 OJ 上刷题时，觉得自己对这个方向感兴趣，并且愿意花大量时间训练。**

> 明确不建议：**想获奖但没兴趣**的同学。没有兴趣支撑，训练会非常枯燥乏味，很可能最后竹篮打水一场空。

## 四、如果你决定打，时间怎么安排

- 越早越好：ACM 的积累是线性的，靠突击没用；
- 和绩点并行：ACM 不能替代绩点，Ⅰ类名额仍然卡前 20%（见 [Ⅰ类-综合成绩排名](../02-本校保研资格/I类-综合成绩排名.md)）；
- 别把 ACM 当成唯一的出路：不进队也可以靠科研、其他竞赛、机试刷题拿到不错的结果。

## 五、给"不打 ACM 但想练算法"的人

不必非得进队。平时的刷题习惯、蓝桥杯、天梯赛都能练机试手感，见 [其他竞赛](其他竞赛.md)。
