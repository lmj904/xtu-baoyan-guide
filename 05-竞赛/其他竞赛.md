# 其他竞赛

> 适用年份：2023 级（2026 年推免）
> 最后更新：2026 年 10 月
> 来源：个人经验 + 学院加分政策

除了 ACM，学校还有大量竞赛。整体规律是：**保研认可度不如 ACM，但难度也相对更低**。具体有哪些、哪个值得打，最直接的办法是问你们班的**学辅、养辅和学长**——他们手里的信息比任何攻略都新。

## 一、门槛较低、适合"以赛带练"的

| 竞赛 | 定位 | 说明 |
| --- | --- | --- |
| **蓝桥杯** | 认可度有限，但适合练手 | 目标可以是冲国一；主要价值是逼自己系统刷题、保持机试手感 |
| **天梯赛** | 门槛低，**不用进队也能打** | 原文提到"联系谢大即可"（具体联系人与当年安排以实际为准） |

这类比赛的真正收益往往不在加分，而在**机试能力**——而机试是复试里最容易拉开差距的环节。

## 二、在推免加分里被认定为 A 类的

按学院政策，下列竞赛**以 A 类竞赛计算**（计分规则见 [竞赛与推免加分](竞赛与推免加分.md)）：

| 竞赛 | 说明 |
| --- | --- |
| **网鼎杯** | 网络安全方向 |
| **强网杯** | 网络安全方向 |
| **全国大学生信息安全竞赛** | 网络安全方向 |
| **湖南省"金种子"杯大学生创业大赛** | 以 A 类**国赛**计算；校级同 A 类校级 |
| **中国国际大学生创新大赛** | 学科交叉 A 类，有 K 系数（见下） |
| **"挑战杯"全国大学生课外学术科技作品竞赛** | 学科交叉 A 类，有 K 系数 |

### 关于"学科交叉 A 类"的 K 系数

挑战杯、中国国际大学生创新大赛这类赛事，计分规则是：

- 以**计算机学院本科生参赛排名顺序前三位**计分；
- 得分为：$A\ \text{类竞赛得分} \times K$，其中 $0.5 \le K \le 1$；
- $K$ 值由**第一署名单位、团队具体排序**等因素确定。

也就是说，同一个奖项，你在团队里排第几、团队以谁的名义参赛，都会影响最终得分。

## 三、还有一类：特殊竞赛（Ⅲ类名额相关）

Ⅲ类奖励指标里提到的"特殊竞赛"包括：

- 国际大学生程序设计大赛亚洲分区赛（即 ACM）
- 中国国际大学生创新大赛（国赛）
- 湖南省"金种子"杯大学生创业大赛（省级）
- "挑战杯"（国赛）

要求达到银奖（国家二等奖）及以上。详见 [Ⅲ类-学校奖励指标](../02-本校保研资格/III类-学校奖励指标.md)。

## 四、怎么选

| 你的情况 | 建议 |
| --- | --- |
| 有 OI 底子、愿意高强度训练 | 冲 ACM（见 [ACM](ACM.md)） |
| 想练机试但进不了队 | 蓝桥杯、天梯赛，以赛带练 |
| 网络安全方向 | 网鼎杯、强网杯、信安竞赛 |
| 有创业/交叉学科项目 | 挑战杯、创新大赛、金种子 |
| 只想拿加分 | 先算投入产出：B 项最多 5 分，同类只取两项最高 |
