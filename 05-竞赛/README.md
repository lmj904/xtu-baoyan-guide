# 05 · 竞赛

竞赛在保研里干两件事：**加分**（本校测评）和**敲门砖**（外校初筛、复试机试）。这一目录讲清哪些竞赛值钱、值多少、怎么选。

## 先给结论

- **想冲外校好学校**：ACM 银牌及以上是改变命运级别的牌（初筛、机试都吃香），但难度极高，且对身体和时间投入要求大；
- **想稳拿本校名额**：竞赛加分在测评里最多 5 分（B 项），同类比赛只取两项最高，别在这里堆太多精力；
- **两者都不追求**：至少把机试能力练出来——蓝桥杯、天梯赛这类门槛低的比赛"以赛带练"，性价比不错。

## 一个反直觉的建议

原文里有一句很值得记住的话：**不要为了加分离散地参加一堆"只用于加分"的竞赛**。把精力集中在一段高质量的科研上，产出（比如一篇 CCF B 以上的论文）既能加分，又能支撑你打比赛，反过来不成立。详见 [初筛与复试](../03-外校复试/初筛与复试.md) 和 [本科生科研入门](../06-科研/本科生科研入门.md)。
