# 本科生科研入门

> 适用年份：2023 级（2026 年推免）
> 最后更新：2026 年 10 月
> 来源：个人经验（作者自述科研参与不多，下列建议偏浅，欢迎补充）

## 一、为什么建议本科生做科研

对湘大（双非）的学生来说，科研是少数**自己能控制、且外校真正认**的东西：

| 收益 | 说明 |
| --- | --- |
| 初筛通过率 | 一篇 CCF B 以上的论文，会明显改善夏令营/预推免的申请结果 |
| 本校加分 | 论文在Ⅰ类测评的 C 项可计 3 分（详见 [论文与期刊分级](论文与期刊分级.md)） |
| 面试素材 | 有科研经历，面试时才有"能讲 5 分钟"的硬内容 |
| Ⅱ类资格 | Ⅱ类（保本校）要求"实质性先进事迹"，论文是第一类认定 |
| 支撑竞赛 | 科研产出往往能顺带支撑比赛，反过来不成立 |

## 二、怎么开始

1. **问学长**：本专业哪些老师接受本科生做科研实习。这是最快、最准的信息来源；
2. **直接联系老师**：带着你的成绩单、做过的项目/课程作业、感兴趣的方向去问（方法见 [套磁](套磁.md)）；
3. **提前进组**：尽早进组做实际的科研工作，而不是等到要用的时候才去找；
4. **从小事做起**：读论文、复现实验、整理数据、跑基线——这些看起来"打杂"的工作是入门必经之路。

## 三、别对科研有滤镜

原文里有一句很重要的话：

> 不要对科研有滤镜，实际上科研不只有天才的灵光一现，普通人也能慢慢推进，本科生也有很多发了优质 paper 的。

现实一点的理解：

- 大部分科研工作是**重复、琐碎、进展缓慢**的；
- 你的第一篇论文很可能不是"大突破"，而是"某个小改进"——这完全正常，也完全有用；
- 能不能出成果，很大程度取决于**组里的方向是否有产出、老师是否愿意带本科生**，而不是你个人是否天才。

所以选组比努力更重要：进组前先打听这个组**有没有本科生发论文的先例**。

## 四、投入产出的取舍

原文的关键建议（针对目标较高的同学）：

> 如果你的目标较高的话，建议集中精力做一段高质量的科研，最好能够有一篇 CCF B 以上的产出……而不是为了加分花太多精力参加很多只用于加分的竞赛。

理由：一篇 CCF B 的论文同时解决"初筛加分"和"复试素材"两件事；而一堆低级竞赛奖项，只能加有限的分（B 项封顶 5 分，同类仅取两项最高，见 [竞赛与推免加分](../05-竞赛/竞赛与推免加分.md)）。

## 五、时间线建议

| 阶段 | 该做什么 |
| --- | --- |
| 大一下 ~ 大二上 | 打好基础（数学、编程、英语），了解各老师的方向 |
| 大二 | 联系老师进组，从读论文、复现开始 |
| 大二下 ~ 大三上 | 参与实际课题，争取做出可写的结果 |
| 大三上 ~ 大三下 | 投稿、出成果；同时开始联系外校老师（[套磁](套磁.md)） |

> ⚠️ **待补充**：湘大计算机学院哪些老师带本科生、各组的产出情况、进组的实际流程与门槛。这类信息随时间变化，最好由在校同学按年份补充。
