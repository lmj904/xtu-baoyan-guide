# 06 · 科研

> ⚠️ 本目录内容相对单薄，只能提供浅显建议。**非常欢迎有科研经历的同学补充**（见 [CONTRIBUTING](../CONTRIBUTING.md)）。

科研在保研里几乎是**投入产出比最高的一张牌**——尤其对双非学生，它比竞赛更可控、更能体现"研究潜力"。

## 三条核心结论

1. **一篇 CCF B 以上的论文，能让你的夏令营和预推免申请顺利很多**（见 [初筛与复试](../03-外校复试/初筛与复试.md)）；
2. **提前进组做科研实习**，对后续的套磁、面试都有实打实的帮助；
3. **别对科研有滤镜**——科研不只有天才的灵光一现，普通人也能一点点推进；本科生发优质论文的不在少数。
