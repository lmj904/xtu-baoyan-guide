# 论文与期刊分级

> 适用年份：2023 级（2026 年推免）
> 最后更新：2026 年 10 月
> 来源：学院加分政策 + 通识整理

"发论文"这句话没有意义——**发在哪**才决定它值多少钱。这一页解释常见的几种分级，以及它们在校内加分里对应多少分。

## 一、CCF 分级（计算机领域最常用）

CCF 指**中国计算机学会**，它维护一份《推荐国际学术会议和期刊目录》，把计算机领域的会议和期刊分成 **A、B、C** 三档：

| 等级 | 含义（通俗理解） |
| --- | --- |
| **CCF A** | 领域顶会/顶刊，公认最难 |
| **CCF B** | 高水平，**保研语境下"有一篇就很能打"的门槛** |
| **CCF C** | 有一定认可度，入门级国际会议/期刊 |

要点：

- CCF 目录**按版本更新**，投稿时和认定时的版本可能不同；
- 学院认定时，以**论文发表时**该期刊/会议所属目录版本为准（见 [Ⅱ类-三教授联名](../02-本校保研资格/II类-三教授联名.md)）。

## 二、其他常见分级

| 分级 | 说明 |
| --- | --- |
| **中科院分区** | 中科院文献情报中心对期刊的分区（一区最好，四区最差），国内高校常用 |
| **SCI 分区** | JCR 分区，按影响因子排名划分 |
| **EI** | 工程索引，覆盖期刊与会议，认可度低于 SCI |
| **北大核心** | 《中文核心期刊要目总览》收录的中文期刊 |
| **CSSCI / CSCD** | 中文社科 / 中文科技引文索引 |

## 三、校内加分对应（Ⅰ类 C 项，上限 3 分）

前提：成果须在**在校期间**取得，且**第一完成单位须为湘潭大学**。

| 成果 | 分值 |
| --- | --- |
| CCF B 类国际期刊/会议、中科院大类一区、二区期刊 | 3 |
| SCI 一区 | 2.5 |
| CCF A 类中文期刊、CCF C 类国际会议/期刊、SCI 二区 | 2 |
| EI 期刊、授权发明专利 | 1 |
| 专利进入实审期 | 0.2 |

两个细节：

- 专利**限两项**；CCF A 类国际会议/期刊**另行讨论**；
- 论文指导老师为一位、学生为**二作**的，视为**一位**加分。

完整计分见 [Ⅰ类-测评计分办法](../02-本校保研资格/I类-测评计分办法.md)。

## 四、"好论文"对外校的含义

注意：**不同学校对"好"的定义不同，有的严格、有的宽松**（原文表述）。

- 严格的地方：只认 CCF A/B，或只认一区；
- 宽松的地方：SCI 三四区、EI 会议也可能被认可；
- 但整体的基准线在往上走：原文判断一篇 **CCF B 以上**会让夏令营/预推免顺利很多。

所以如果你的目标是"用论文提升初筛通过率"，**瞄准 CCF B 及以上**是相对稳妥的策略。

## 五、Ⅱ类（保本校）的额外要求

Ⅱ类要求"实质性先进事迹"，论文这一类要求：

- **独立作者或第一作者**；
- 发表在 SCI、EI 源刊、CCF A/B/C 类会议及期刊、SSCI、A&HCI、CSSCI 及其扩展版、CSCD、北大核心收录的期刊上；
- 内容须**与学业相关**；
- 期刊认定以**发表时**目录版本为准。

## 六、几点现实提醒

- **第一完成单位必须是湘潭大学**才能加分——挂外校单位的成果不计分；
- 论文从投稿到见刊/录用往往要半年以上，**大三下才开始基本赶不上当年认定**；
- 会议论文同样可以计入 CCF 分类，别只盯着期刊；
- 一篇文章的"作者顺序"在校内加分和Ⅱ类认定里都有实际影响，进组前就该和老师谈清楚。
